A structured, hands-on **90-day learning series** designed to take learners from foundational AI and Python concepts to building, evaluating, and deploying practical Generative AI, Retrieval-Augmented Generation (RAG), and Agentic AI applications.

- **Full Curriculum:** [genai_roadmap.md](https://github.com/Rajkumar-Ai-Engineer/GenerativeAI-90-days-series/blob/main/genai_roadmap.md) | [genai_roadmap.pdf](https://github.com/Rajkumar-Ai-Engineer/GenerativeAI-90-days-series/blob/main/genai_roadmap.pdf)
- **Daily Commitment:** 2–3 Hours/day (recommended 2.5 hours / 150 minutes)
- **Approach:** Theory + Hands-on Coding + Assignments + Weekly Projects

---

## Program Objectives

By completing this 90-day program, learners will be able to:

1. Understand Artificial Intelligence, Machine Learning, Deep Learning, and Generative AI.
2. Understand NLP, Transformers, and Large Language Models (LLMs).
3. Work with commercial and open-source LLMs.
4. Integrate LLMs using APIs.
5. Apply Prompt Engineering techniques.
6. Build applications using LangChain.
7. Understand embeddings and vector databases.
8. Develop Retrieval-Augmented Generation (RAG) applications.
9. Build AI agents and agentic workflows.
10. Use LangGraph to develop stateful AI applications.
11. Evaluate LLM and RAG applications.
12. Deploy GenAI applications using FastAPI and Streamlit.
