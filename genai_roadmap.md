# 90-Day Generative AI Learning Roadmap
## Beginner to Job-Ready GenAI Application Developer

**Duration:** 90 Days (3 Months)  
**Level:** Beginner to Intermediate  
**Daily Commitment:** 2–3 Hours  
**Learning Approach:** Theory + Hands-on Coding + Assignments + Projects

---

# 1. PROGRAM OBJECTIVE

The objective of this 90-day program is to help beginners understand Generative AI from its fundamentals and gradually develop the skills required to build real-world AI applications.

By the end of this program, learners should be able to:

1. Understand Artificial Intelligence, Machine Learning, Deep Learning and Generative AI.
2. Understand NLP, Transformers and Large Language Models.
3. Work with commercial and open-source LLMs.
4. Integrate LLMs using APIs.
5. Apply Prompt Engineering techniques.
6. Build applications using LangChain.
7. Understand embeddings and vector databases.
8. Develop Retrieval-Augmented Generation (RAG) applications.
9. Build AI agents and agentic workflows.
10. Use LangGraph to develop stateful AI applications.
11. Evaluate LLM and RAG applications.
12. Deploy GenAI applications using FastAPI and Streamlit.

# 2. TECHNOLOGY STACK

| Category | Technologies |
|---|---|
| Programming | Python |
| Data Processing | NumPy, Pandas |
| NLP | NLTK, Hugging Face |
| LLMs | GPT, Gemini, Llama |
| LLM APIs | OpenAI, Groq, Gemini |
| Frameworks | LangChain |
| Agentic AI | LangGraph |
| Embeddings | Hugging Face Embeddings |
| Vector Databases | ChromaDB, FAISS |
| Document Processing | PyMuPDF |
| Backend | FastAPI |
| Frontend | Streamlit |
| Evaluation | RAGAS, LangSmith |
| Deployment | Hugging Face Spaces, Render |
| Version Control | Git and GitHub |
